1准确率 / 精确率 / 召回率 / F1

用「模型答得对不对」二分类来记：

指标含义怎么算
准确率 Accuracy 全部里判对的比例 对的 ÷ 总数
精确率 Precision 判成「对」的里，真是对的 TP ÷ (TP+FP)
召回率 Recall 真是「对」的里，被抓出来的 TP ÷ (TP+FN)
F1 精确与召回的折中 2·P·R / (P+R)
一句话口诀 精确率高 = 少冤枉（判对里少假的）；召回率高 = 少漏掉。医疗问答往往更怕漏（重召回）。

测试/评测里还会用到

  • 通过率：用例是否满足预期（你项目里的指标）
  • 引用命中 / 溯源率：回答是否落在知识库来源
  • 风险拦截率：高风险问题是否拦住
  • 延迟 P50 / P95：接口耗时

2模型幻觉（必考）

标准定义（背） 模型生成了看起来合理、但与事实 / 知识库 / 输入不符的内容。例如编造不存在的药品名、文献，或知识库没写却给出「糖尿病患者不能吃某水果」。

测试上怎么抓

  1. 库里有的题：看能否答对、引用是否命中来源
  2. 库里没有的题：应拒答 / 说不确定，而不是瞎编
  3. 错误前提：给矛盾信息，看是否跟着错（如男性开妇科药）

3等价类划分 + 边界值

等价类划分

输入分成有效 / 无效若干类，每类抽 1 个代表，不穷举。

文件上传 · 有效

PDF、Word、Markdown、TXT、正常大小

文件上传 · 无效

exe、0KB、超大文件、假后缀（.pdf 实为 zip）

特殊类

加密 PDF、扫描件、带密码 Word、损坏文件

边界值

限 10MB → 0、1B、10MB-1、10MB、10MB+1

口头答题模板

先按等价类分有效/无效 → 在边界取点 → 补异常 / 兼容 / 安全类。

4bad case（别再答「没遇到」）

定义：模型或流程结果不符合预期的样例。

四步处理

  1. 记录：输入、模型输出、期望输出、复现步骤
  2. 归类：幻觉 / 漏检索 / 意图错 / 解析错 / 边界未覆盖
  3. 补用例：进回归集，防止再坏
  4. 反馈：给算法/研发，必要时改数据、prompt、规则
项目怎么套 「我项目里高风险问题会进拦截 + 人工复核，这类必须人工确认的结果，就是我们口径里的 bad case 流。」

5开发不认 bug

  1. 对齐标准：需求文档 / 原型 / 验收标准，先分清是 bug 还是需求不清
  2. 补证据：复现步骤、环境、截图/录屏、日志、期望 vs 实际
  3. 评估影响：概率、影响用户、是否堵主流程
  4. 仍分歧：拉产品 / 测试负责人，按优先级走，不硬吵
  5. 安全类要坚持；争议可记「待确认」，但别静默关闭

7现场可复用的 Python 片段

# 评测通过率统计
import json
total = pass_n = 0
for line in open("results.jsonl", encoding="utf-8"):
    row = json.loads(line)
    total += 1
    pass_n += int(row.get("pass", False))
print(f"通过率 {pass_n}/{total} = {pass_n / total:.2%}")
